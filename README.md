# Civil Experts · DPCS – Site Report

*Clear Project Control. Better Construction Decisions.*

Mobile web app (PWA) for daily site engineering field reports.
Part of **DPCS – Digital Project Control System** by Civil Experts PMC.

- Open the site on any phone → fill the report → **Submit** → saved to the project Google Sheet.
- Chrome → ⋮ → **Install app / Add to Home screen** to use it like an app; it also opens offline and syncs when back online.
- Daily DPR is generated automatically (n8n) and saved to Google Drive.
